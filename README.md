# Gramavasi

Stories, Vedic chants and village life from Chakicherla, coastal Andhra Pradesh.
Live at https://gramavaasi.github.io

- `index.html` — the whole site (stories, quotes, village gallery, chant player)
- `img/` — photos from the blog posts
- `v/` — village gallery photos (`l` large, `t` small)
- `chant.mp3`, `drone.mp3`, `narayana.json` — Narayana Suktham player

To fix a word in a story: open `index.html`, click the pencil icon, edit, and "Commit changes". The site updates in about a minute.
